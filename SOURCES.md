- **HKO Weather Warnings** — CORS allow-origin * so the browser can fetch directly. Returns {} when no warning is in force. Otherwise keyed by warning code with name, code, actionCode, issueTime, updateTime, expireTime.
- **HKO Detailed Weather Warning Information** — Full warning text, useful for a detail drawer.
- **HKO Current Weather (temperature, humidity, rainfall, UV)** — temperature.data[] per place, humidity, rainfall.data[] per 18 districts, uvindex, icon. recordTime/updateTime fields carry the observation time.
- **HKO Special Weather Tips** — Returns a nearly-empty body when nothing is active.
- **HKO Tidal Information** — SOLVED: tide is HHOT (UPPERCASE) and lives on opendata.php, NOT weather.php. Needs station (QUB, CCH, ...) + year; month/day/hour optional. HLT returns astronomical high/low tides. Both verified 200 JSON.
- **HKO Ambient Gamma Radiation Level** — SOLVED: ambient gamma dose rate is dataType=RYES (Weather and Radiation Level Report) on opendata.php. Needs station + date (YYYYMMDD, up to yesterday). The earlier guesses rmn/radiation were wrong.
- **HKO Quick Earthquake Message** — SOLVED: earthquakes live on a SEPARATE endpoint, earthquake.php — not weather.php. qem = worldwide M6+ quick report (lat/lon/mag/region/ptime); feltearthquake = locally felt tremors (returns {} when none, which is a valid empty result, not an error).
- **HKO Weather Radar Image (256 km)** — FOUND. The URL is a TEMPLATE, not a fixed file: {YYYYMMDDHHMM} is the frame time in Hong Kong time on a 6-minute grid. radarCandidates() in web/src/lib/parsers.ts owns the substitution and steps back (now, -6, -12, -18) until one returns 200. A literal timestamp must NEVER be committed here — the original probe recorded a fixed sample URL, which 404s within minutes and reads as a dead source when the source is fine. That mistake was made once and cost a debugging cycle.
- **HKO Satellite Image** — FOUND. Also a TIMESTAMPED path under /wxinfo/intersat/satellite/image/asia/ — the filename carries a date plus an offset token, so the exact naming rule still needs pinning. ~216KB.
- **Open-Meteo Wind Field Grid (352 points, for the flow animation)** — The only registered source that returns a LATTICE rather than a point, so it is the only one that can drive a flow animation. MEASURED: 352 points in one request, 144KB, ~0.9s, every point populated (sample day: speed 4.1-18.4 km/h, direction 37-68°). This is MODELLED data and the legend says so — the weather_stations layer is the OBSERVED counterpart, and conflating the two would be the dishonest option.
- **EPD Air Quality Health Index (by monitoring station, RSS)** — FOUND — the official EPD feed (data.gov.hk dataset hk-epd-airteam-current-aqhi-of-individual-air-quality-monitoring-stations). Each item's title is the station name and the description carries '<station> - <type>: <AQHI> <risk>'. ChT/ChS variants alongside. Host is www.aqhi.gov.hk — the bare aqhi.gov.hk does not resolve.
- **EPD AQHI Past 24 Hours by Station** — The file the aqhi.gov.hk page itself loads. It is JavaScript, not JSON: 'var station_24_data = [...]'. Strip the 'var ... = ' prefix then parse. Per-station hourly rows with StationID, DateTime, StationNameEN/CT/CS, aqhi and NO2/O3/SO2/CO/PM10/PM25 — i.e. the full pollutant breakdown, ~226KB.
- **EPD AQHI Forecast / Health Risk Levels** — 'var aqhi_report = [...]' with DateTime, StationTypeEN, AQHIRiskEN, AQHIRange. Strip the var prefix.
- **HKO WBGT Heat Stress Index (every 10 min)** — 濕球黑球溫度 — 戶外工作與運動嘅真正熱壓力指標，比氣溫誠實得多。對露營、賽事、地盤、跑步都直接有用。
- **HKO Gridded Rainfall Nowcast (every 12 min)** — 格網狀未來降雨預報 —— 可以砌落雨動畫／時間軸，係整個天氣層最有動感嘅一個。另有 _tc 中文版。
