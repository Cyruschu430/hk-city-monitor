01係咩

一個淨係用瀏覽器開嘅城市情報儀表板

香港城市監察用一套確定性規則引擎，解讀香港政府同公共機構嘅開放數據。運行時完全冇 LLM，冇 cookie，冇追蹤，冇帳戶，冇伺服器，冇資料庫 —— 開個網頁，就係全部。

數據嚟自香港政府部門同公共機構（CSDI 空間數據共享平台、data.gov.hk 等等）。每個來源沿用佢自己嘅授權，儀表板逐項標明出處同新鮮度。

誠實

冇一個數字係作嘅。每個數字都列明來源、連結同攞數時間；數據過咗新鮮期會明顯變黃／變紅，唔會扮新鮮。

02有咩睇

十個模式，每個都答一條你真係會問嘅問題

颱風模式會唔會掛 8 號？聽日飛唔飛得成？
口岸模式而家過關要等幾耐？
停水模式我嗰區有冇停水？幾時回復？
天氣模式今日會唔會落雨？要唔要帶遮？
交通模式而家邊條路塞？下一班車幾時到？
無人機模式而家飛唔飛得？邊區有風、邊度禁飛？
貨運模式貨運物流而家有冇阻滯？
醫療模式急症室等幾耐？邊度有 AED？
民生模式我嗰區有冇停水／停車位／空氣差？
直擊模式而家香港發生緊咩事？

面板（節錄）

城市簡報（每日兩次由排程工作生成、以靜態 JSON 發布 —— 運行時仍然零 LLM）、天氣警告、空氣質素健康指數、港鐵下一班車、九巴到站時間、口岸輪候、停車場空位、停水、航班、市況、攝影機牆、直播。

03點運作

規則引擎，唔係黑盒

  • 16 條確定性規則，覆蓋 5 個範疇。 決定「有冇事、幾嚴重」嘅係門檻值，唔係模型。
  • 運行路徑零 LLM。 唯一有 AI 參與嘅係每日兩次嘅城市簡報，由排程工作寫好、當靜態檔案發布；你用緊嗰陣，瀏覽器冇生成任何嘢。
  • 冇 cookie、冇追蹤、冇帳戶、冇資料庫。
  • 每個數字都可溯源。 來源名、連結、攞數時間。過咗新鮮期就明顯降級，唔會硬扮 live。
04啱邊個

俾想一眼睇清香港嘅人

  • 住喺香港嘅人 —— 出門口前睇天氣、交通、口岸、停水。

  • 開源情報（OSINT）愛好者 —— 可溯源、開放、可自架。

06本地運行

開源，你可以自己起一個

成個嘢係一個靜態 bundle，任何靜態伺服器都 serve 到。本地試：

# 1. clone 落嚟
git clone https://github.com/Cyruschu430/hk-city-monitor
cd hk-city-monitor/web

# 2. build 同 preview
npm ci
npm run build
npx vite preview --host 127.0.0.1 --port 4173

然後開 http://127.0.0.1:4173。完整自架教學見 repo 嘅 SELF_HOSTING.md。
