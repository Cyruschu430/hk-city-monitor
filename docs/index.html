01What it is

A city-intelligence dashboard that runs entirely in the browser

HK City Monitor consolidates open data published by Hong Kong government departments and public bodies onto one live map. There is no server component, no database, no account and no tracking: the application is a static bundle that reads from public endpoints directly.

Data comes from the CSDI spatial data platform, data.gov.hk and institutional publishers such as the Observatory and the Airport Authority. Each source keeps its own licence, and the dashboard credits every source and reports its freshness.

Honesty

No figure is invented. Every number shows its source, a link and the time it was read. Past its freshness window a panel visibly degrades rather than presenting stale data as current.

Panels (a selection)

A city brief (written twice a day by a scheduled job and published as a static JSON file), weather warnings, air-quality health index, MTR next trains, KMB bus ETAs, cross-boundary queues, carpark vacancy, water-suspension notices, flights, markets, camera walls and live streams.

03How it works

Explicit thresholds, not a black box

  • Severity is a threshold over published values, not a model. What counts as “something is up” is a declared comparison against the publisher's own figures.
  • A context engine can activate a mode automatically. When declared conditions are met — a typhoon signal is hoisted, a water-suspension notice is in force — the matching mode is selected. The rules are data, not code, and are unit-tested.
  • No LLM in the runtime path. The only AI involvement is the twice-daily city brief, written by a scheduled job and published as a static file; while you use the dashboard, the browser generates nothing.
  • No cookies, no tracking, no account, no database.
  • Every figure is traceable. Source name, link and read time — and past its freshness window it degrades visibly rather than faking live.

For people who want Hong Kong at a glance

05Data & licences

Every source has an attribution and a licence

All data is published openly by Hong Kong government departments and public bodies. Each source keeps its own licence; the project does not republish content, it presents data and links back to the original. Sources, licences and refresh cadences are itemised in ATTRIBUTION.md.

  • CSDI and data.gov.hk — government open data.
  • Basemap: Lands Department (LandsD) topographic tiles.
  • Aerial imagery: Esri World Imagery. (“Powered by Esri”)
  • A small number of source licences are still being confirmed — see the repository.
06Run it locally

Open source — run your own

The whole application is a static bundle that any static host can serve. To try it locally:

# 1. clone
git clone https://github.com/Cyruschu430/hk-city-monitor
cd hk-city-monitor/web

# 2. build and preview
npm ci
npm run build
npx vite preview --host 127.0.0.1 --port 4173

Then open http://127.0.0.1:4173. The full self-hosting guide, including the edge proxy and the optional scheduled collectors, is in SELF_HOSTING.md.
